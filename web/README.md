# Tag Cake website

Vue 3 + TypeScript, built with Vite. All copy is in Azerbaijani.

```bash
npm install
npm run dev              # local development
npm run build            # type-check + production build → dist/ (upload this folder to any host)
npm run build:artifact   # single-file build for the shareable preview page → dist-artifact/artifact.html
```

- Products and their text: `src/data/catalog.ts`
- WhatsApp / Instagram links (TODO: fill in): `src/config.ts`
- Styles and brand colours: `src/styles/main.css`
- Photos and hero video: `public/img`, `public/media`
